## 定位

一次攻击是包含伤害（治疗）量和多种属性的数据包。伤害属性用于筛选可生效的效果。本表为完整枚举参考；伤害计算方式见《伤害计算基本公式》，机制解析见《伤害底层机制》。

## 伤害类型（damageType）

| 类型 | 特性 |
|:--|:--|
| 物理 | 计算目标防御力 |
| 法术 | 计算目标法术抗性 |
| 真实 | 不计算任何防御属性；不指定伤害类型的伤判效果可对其生效（可被减免、格挡或闪避） |
| 治疗 | 用于治疗行为；默认受禁疗约束（治疗类能力 = 直接治疗与伤害类型为治疗的攻击，增减生命回复速度类不算） |
| 元素 | 计算目标元素抗性；损伤抵抗用于减免元素损伤值 |

注：伤害计算中的"使用属性"大多数为自身攻击力，也存在基于其他属性、目标属性或固定值的情况。

## 攻击类型（attackType）

| 类型 | 特性 |
|:--|:--|
| 无类型（NONE） | 占位，不算实际攻击类型 |
| 普通（NORMAL） | 最常见；省略时默认为此类型，但对筛选省略即不判断 |
| 溅射（SPLASH） | 常见于对群伤害，但部分群攻只造成普通伤害 |
| 持续（BUFF） | 通过对目标施加持续效果造成的伤害，大多数毒伤/DOT 即此类型 |
| 附加（ADDITION） | |

## 施加途径（applyWay）

| 类型 | 特性 |
|:--|:--|
| 无途径（NONE） | 部分 Buff 造成；近战与远程的格挡都可格挡 |
| 近战（MELEE） | 不产生弹道的攻击；与"被阻挡时普攻"无对应关系，与图鉴攻击方式标签无关 |
| 远程（RANGED） | 产生弹道的攻击 |
| 全途径（ALL） | 极少部分 Buff 造成 |

## 标签（sharedFlag）

| 标签 | 效果 |
|:--|:--|
| 非致命伤害 | 至多将目标生命值降至 1 点，重伤机制使用 |
| 环境伤害 | 环境造成的伤害 |
| 生命流失 | 跳过伤害计算以外的所有步骤与事件，基本确保原样生效；通常配真实伤害，非真实的标注"物理流失/法术流失" |
| 可影响沉睡单位的伤害 | 可对沉睡单位生效 |
| 溢出部分可产生屏障的治疗 | 记录溢出治疗量并触发响应事件 |
| 强制显示红字的伤害 | 始终视为暴击展示红字 |
| 类斩杀伤害 | 部分效果不响应（如愧悔魂灵圣杯光环） |
| 不可变的伤害 | 不受大部分变动伤害逻辑影响 |
| 撼地者主目标伤害 | 享受与撼地者普攻主目标等同的攻击力倍率 |
| 撼地者溅射目标伤害 | 享受与撼地者普攻溅射目标等同的攻击力倍率 |

## 杂项分类

| 分类 | 说明 |
|:--|:--|
| 预计算伤害 | 计算与造成逻辑分离，通常无"伤害计算时"事件；所有缓存攻击力的伤害均属此类 |
| 计算后伤害 | 连防御/抗性和攻击力倍率增减都无法处理 |
| 普通攻击的伤害 / 技能攻击的伤害 | 攻击本身造成的伤害，不含攻击附加的 Buff 造成的伤害 |
| 无来源 | 无法追溯伤害来源；击杀来源追溯不受影响 |
| 致命伤害 | 理论上能使生命值不大于 0 的伤害，触发致命相关时点；与非致命可共存于同一次伤害 |
| 弱点伤害 | 游戏内术语：临时比较理论物理与理论法术伤害，转更高一方，详见《伤害底层机制》弱点伤害节 |

## 攻击附加效果顺序

- 攻击本身附加的 Buff 先于攻击本身的伤害生效
- 攻击本身附加的元素损伤晚于攻击本身的伤害生效（经附加 Buff 施加的不受此限制）
- "先造成伤害再施效果"由攻击力 0% 伤害 + 附加顺序 Buff 实现
