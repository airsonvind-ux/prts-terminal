## 一、什么是弹道

弹道又称抛射物。弩箭、导弹、锁链、飞向敌人的鸟、爆炸范围效果、环绕飞行的小球都是弹道。弹道携带完成一次攻击所需的信息，是远程攻击的核心。

判断一个攻击是否为弹道的粗略方法：攻击伤害与特效即时发生的不是弹道，需要一段时间生效的即为弹道。部分攻击看似有弹道（如能天使的普通攻击），但"子弹"仅为特效，实际不产生弹道。

## 二、移动方式

弹道的移动行为决定它视觉上如何运动，视觉效果通常与实际移动方式无关。

| 移动方式 | 行为 | 移动类型 |
|---|---|---|
| 静止 | 固定在原地，不移动 | 不可变 |
| 直线 | 以当前位置直线向目标移动 | 可变 |
| 抛物线 | 抛物运动（如炮手的炮弹）；具体移动方式待补充 | 可变 |
| 环绕 | 根据角速度与半径绕目标旋转（如特蕾西娅的永恒尘埃） | 可变 |
| 向前飞行 | 无限往一个方向直线飞行，将碰撞到的可选对象视为目标（如马特奥上尉） | 可变 |
| 捕网 | 如雪雉的捕网；具体移动方式待补充 | 可变 |
| 附着 | 直接在目标上出现，不移动，可配置为跟随目标移动 | 不可变 |
| 套索弹道 | 持续锁定目标，在发出点与目标之间画出一条线；先直线向目标移动，之后跟随目标移动 | 不可变 |
| 定时命中 | 子弹飞向目标，命中时间固定，飞行速度由距离与时间计算（如阿米娅的普攻与二技能） | 不可变 |
| 组合 | 多种移动方式的组合；具体移动方式待补充 | 特殊：需包含的移动方式全部为可变才为可变 |

## 三、转向速度

部分弹道存在转向机制。转向速度表示弹道速度（向量）向目标方向变化的权重，格式为 A/B：B 为总权重，A 为目标方向占的权重，B−A 为本帧速度方向占的权重。

每个下一帧，弹道方向变化为：本帧方向 × (B−A)/B + 目标方向 × A/B。

例：弹道位于 (0,0)，敌人位于 (10,10)，弹道速度始终为 10，本帧方向为 (1,0)，转向速度为 1/5，目标方向为 (0.7071,0.7071)，则下一帧方向 = 4/5 × (1,0) + 1/5 × (0.7071,0.7071) = (0.94142,0.14142)，下一帧速度为 (9.4142,1.4142)。

## 四、最大存在时间

大部分有目标的弹道具有最大存在时间参数，决定弹道从出现开始最多能存在多长时间，达到上限后自动消失。

- 存在时间归零时，若弹道仍未击中目标，则立刻视为击中了目标（可配置）
- 大量弹道的存在时长为 3 秒、5 秒、10 秒（可配置）
- 部分技能与其创建的弹道绑定：弹道因各种原因无法消失时，相关技能可能持续维持到弹道自动消失为止

## 五、可变速与可消除模式

部分效果（如逻各斯三技能延异视阈）能降低攻击范围内敌方子弹的飞行速度、或将其全部清除。能否生效由弹道的可变速模式与可消除模式决定，各有三种设置：

- **自动识别（AUTOMATIC）**：可变速模式下，弹道包含可见视觉特效则可被减速，否则不可；可消除模式下，结果与可变速模式一致（可减速即可消除）
- **可变速 / 可消除（YES）**：可被减速 / 消除
- **不可变速 / 不可消除（NO）**：不可被减速 / 消除

移动类型为不可变的弹道始终不可变速（NO）；移动类型为可变时，其可变速规则待补充。非自动识别模式下，可变速与可消除没有直接关系：可能存在可被减速但无法被消除的弹道，也可能存在可被消除但无法被减速的弹道。
