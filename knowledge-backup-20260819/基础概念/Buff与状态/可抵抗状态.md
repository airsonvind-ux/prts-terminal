## 概念

每个 Buff 自带"抵抗耐性"属性：不可抵抗（默认）、可抵抗、自动识别。被设置为**可抵抗**的 Buff 称为可抵抗状态，其持续时间按可抵抗状态生效时间倍率缩放，常见抵抗的倍率为 0.5，即**持续时间减半**，同时触发类效果更频繁触发。

注意：可抵抗的是**携带异常效果的 Buff**，不是异常效果本身。游戏内"可被抵抗"字样或出现在抵抗描述中的状态，指的就是此类 Buff。

## 常见的可抵抗状态

| 状态 | 说明 |
|:--|:--|
| 晕眩 | 敌方与干员视角均为可抵抗 |
| 寒冷 | 敌方施加的寒冷、干员施加的寒冷分别可抵抗 |
| 冻结 | 敌方施加的冻结、干员施加的冻结分别可抵抗 |
| 恐惧 | 可抵抗 |
| 诱导 | 可抵抗 |

以上状态的标记可用 query_table 工具查询。

## 特殊来源的可抵抗状态

除常见状态外，以下特殊效果也属于可抵抗状态（对应 Buff 被标记为可抵抗）：

- 塔露拉与不死的黑蛇释放的"烈焚灼息"
- 烹泉与沏虹死亡后造成的攻击速度降低
- 青花与赤霞的技能"侵蚀之流"造成的持续递增法术伤害
- 岁相的技能"天坠"造成的持续递增法术伤害
- 生息演算「沙洲遗闻」骄阳天与烈阳天施加的燃烧
- 缇缇的技能施加的包含小睡异常的 Buff

## 例外

本应为可抵抗状态、却因特殊原因被重写为不可抵抗（或漏写可抵抗）的 Buff，无法被干员的抵抗减半，也无法被流明的技能反应、被佩佩的技能无视：

- 来自子代、茧缚、"木衣"造成的晕眩
- 来自伊祖米克，生态泉源【震撼】②效果部分

## 相关机制

- 可抵抗状态的持续时间同样受其他异常状态持续时间延长/缩短效果的影响
- 状态免疫（异常效果）可阻止可抵抗 Buff 被添加
- 敌人的异常抗性字段列出的是该敌人免疫的异常效果，与可抵抗状态是两个维度：免疫决定"能不能中"，可抵抗决定"中了能不能被减半"
