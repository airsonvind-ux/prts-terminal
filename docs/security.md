# 安全边界

## 信任模型

- **LLM 不可信**：模型只能提出工具调用，不能直接执行命令、读写任意路径或修改审批策略。
- **前端不可信**：前端可以展示状态，但权限判断、路径解析和执行必须由 Rust 层完成。
- **外部更新源不可信**：清单和安装包必须验签；签名版本与清单版本不一致时拒绝。
- **本地数据是用户资产**：会话、记忆、凭据和附件不因更新、压缩或启动失败而被静默覆盖。

## 控制面

### 工具审批

需要审批的调用会生成审批卡。拒绝、取消和超时会形成明确的工具结果，不会让 Agent 误以为执行成功。

### 命令执行

- 默认使用受限令牌
- 通过 Job 对象约束子进程生命周期
- 只对工作区和必要临时目录临时放行 ACL
- 超时和取消会终止进程树

### 路径

- 文件工具经过路径守卫，阻止目录穿越和受保护路径写入
- 工具的工作区根与用户的配置一致，不信任前端传入的任意路径

### 凭据

API key 使用本机用户绑定的加密存储；设置文件只保存掩码或引用，不保存明文。已保存的密钥只由后端复制到系统剪贴板，前端只显示末 4 位提示，完整钥值不返回渲染进程。

### 更新

- 清单必须签名
- 下载前检查磁盘空间
- 安装前再次检查活跃 turn 和 MAA 任务
- 失败阶段区分检查、下载、磁盘和安装，避免把不同问题报成同一种错误

### 网络抓取

- 仅允许 http/https；重定向手动逐跳处理，最多 5 跳
- 每跳校验主机：IP 字面量直接分类，域名全量解析后逐 IP 检查
- 解析结果固定到本跳客户端，连接阶段不再重新解析 DNS，封死重绑定窗口
- 拒绝回环、RFC1918、链路本地、CGNAT、文档/保留段、组播，以及 IPv6 ULA/
  链路本地/组播/文档段
- 响应体 1MiB 流式硬上限；禁用代理，不读取环境代理配置

### 前端内容

- Markdown 渲染经过清洗
- 外部链接通过受限打开接口处理
- Tauri 能力按窗口最小化配置
- CSP 覆盖脚本、样式、图片和本地 IPC；不为方便关闭 CSP

## 报告问题

安全问题不要公开提交 issue。请通过仓库维护者提供的私密渠道报告，并附上复现步骤、影响范围和版本号。不要在报告中粘贴真实 API key、会话内容或本机路径。
