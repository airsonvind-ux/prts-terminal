# PRTS Terminal 0.1.3

数据对齐与 MAA 安装目录修复。

## 本版内容

### 数据

- 同步 2026-11-10 数据版本（dataVersion `2026.11.10`），对应客户端 2.7.91

### 修复

- MAA 安装目录识别不到：自动检测现在会遍历常见安装与下载位置；设置页新增「MAA 目录」一项，可手动指定、可重新检测，并显示当前生效路径来自手动指定还是自动检测

## 已知情况

- 本版仅做数据对齐。Wiki 侧页面仍在更新，后续版本会持续更新同步

## 安装

下载 `PRTS Terminal_0.1.3_x64-setup.exe` 并运行安装程序。

已安装旧版本的用户会在启动后收到更新提示，更新包使用 Tauri 签名校验；安装包 SHA-256 见发布目录中的 `SHA256SUMS.txt`。
