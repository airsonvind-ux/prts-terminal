# PRTS Terminal 0.1.0

首个公开版本。

## 本版内容

- Tauri 桌面壳与 React 前端，面向 Windows x64
- Agent turn 循环、工具调用、审批、取消与上下文压缩
- 干员、敌人、关卡、肉鸽与表格查询工具
- 随包知识库、技能与使用说明
- 本地会话、记忆、设置与加密凭据
- MAA 独立桥进程（AGPL）与可选集成
- Gitee 主源、GitHub 兜底的签名更新链路
- 同步 2026-10-25 游戏数据（dataVersion `2026.10.25`）

## 安装

下载 `PRTS Terminal_0.1.0_x64-setup.exe` 并运行安装程序。

更新包使用 Tauri 签名校验；安装包 SHA-256 见发布目录中的 `SHA256SUMS.txt`。
