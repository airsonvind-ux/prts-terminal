# PRTS Terminal 0.1.2

Wiki 数据补充与插件系统。

## 本版内容

### 数据

- 同步 2026-11-06 数据版本（dataVersion `2026.11.06`），对应客户端 2.7.91
- 从 PRTS Wiki 对齐了补充信息

### 插件系统

- 支持外部插件：把插件文件夹拖到设置里的插件页即可安装，可随时启用、停用、卸载
- 插件能力需在清单中声明，声明范围之外的调用会被拒绝
- 提供 Python 与 Rust 两种插件模板，以及随包插件开发手册（从快速开始到发布、排错共十篇）
- 提供 `plugin_check` 校验器，可在开发时检查清单、能力、工具定义与文案
- 内置插件体系落地，MAA 集成改由内置插件承载

### 界面

- 消息流改版：思考过程与工具调用按发生顺序分块显示，过程卡可收起，收起时显示思考段数与调用次数
- 工具调用行显示执行状态，失败的调用在摘要里标出数量
- 新增情绪标识卡，按语气与强度着色
- 插件工具可以附带视图：在沙箱中渲染插件自带的页面，页面里的点击可以回传并触发后续调用
- 记忆页重排，当前记忆单独成页，整理前需确认
- 上下文压缩与插件生效的提示改用具体数字说明，不再出现内部阈值名

## 已知情况

- 插件系统为首个稳定版本，接口按最终形态实现，暂不提供兼容层

## 安装

下载 `PRTS Terminal_0.1.2_x64-setup.exe` 并运行安装程序。

已安装旧版本的用户会在启动后收到更新提示，更新包使用 Tauri 签名校验；安装包 SHA-256 见发布目录中的 `SHA256SUMS.txt`。
