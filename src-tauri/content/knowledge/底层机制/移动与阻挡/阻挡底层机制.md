## 判定模型

我方单位的受击判定区域为半径 0.25 的圆，敌方单位为半径 0.1 的圆；物理碰撞箱为宽 0.2、高 0.4、向下偏移 0.1 的胶囊型。两者均与阻挡机制无关。

阻挡只使用角色类单位（干员、召唤物、关卡装置）的阻挡半径，判定方式为角色中点与敌人中点距离 ≤ 阻挡半径（内部以半径平方数比较）。干员与召唤物默认地面阻挡半径 0.707（= 0.5√2，单位格对角线长度的一半，平方 0.49999037）。阻挡偏移机制（见下节）会把距离不足 0.5 的敌人调整到 0.5 处，习惯上称 0.707 为外阻挡圈、0.5 为内阻挡圈。飞行阻挡半径 = 0.8944 × 阻挡半径倍率（平方 0.79995137 × 倍率²，干员默认倍率 1）。

装置覆写阻挡半径，覆写后地面与飞行判定统一使用覆写值；装置没有阻挡偏移机制，内圈 0.5 不适用于装置。如碎石阻挡半径 0.4472（平方约 0.2），巨型装置固定为 0.49999037。

每 3 帧扫描一次阻挡半径内未被阻挡的敌人，多个候选时优先阻挡距离最近的。

## 阻挡偏移

### 触发前提

一般情况下敌人被阻挡后，其位置会按下面的规则被调整（即阻挡偏移）。仅当敌人与阻挡位的中点几乎完全重合（距离小于 0.00001，例如出生在方格正中心、尚未开始行动的敌人）时不发生偏移。

### 单个敌人

以阻挡位为圆心观察：若敌人距离阻挡位不足 0.5 格（例如空降干员落在敌人附近），敌人的位置会被调整，沿"阻挡位指向敌人"的方向移动，直到与阻挡位相距 0.5 格；若敌人原本就在 0.5 格以外，则位置不变。

### 多个敌人

阻挡位已经挡着若干敌人时，新来的敌人先确定自己的**基础位置**：若距阻挡位不足 0.5 格则调整到 0.5 处（同单敌规则），否则保持原位。

若基础位置周围 0.1 格内存在其它已被阻挡的敌人（即存在敌人距离太近的情况），则进入方向修正。计算时遍历**所有**其它已被阻挡的敌人，每个敌人按与基础位置的距离贡献一个修正方向（距离 0.4 格及以上的敌人被遍历但不贡献）：

- 距离小于 0.1 格：贡献方向为"从阻挡位指向该敌人"的向量顺时针旋转 90° 后的单位方向
- 距离在 0.1 到 0.4 格之间：贡献方向为远离该敌人的方向（从该敌人指向基础位置），贡献幅度 = (0.4 − 距离) × 50，距离越近幅度越大

将所有贡献向量相加，所得总向量的方向即为修正方向，长度固定为 0.2 格。最终位置：沿修正方向移动 0.2 格得到临时位置，再将临时位置调整回与基础位置相同的距阻挡位距离（保持距离不变，仅方向改变）。敌人在 0.2 秒内（6帧）被强制移动到最终位置，该位置记录为其稳定阻挡位置；此后各敌人均以稳定阻挡位置参与计算。

## 内外阻挡状态的几何推导

受击圆半径 0.1 与阻挡位所在格（边长 1，边界距中心 0.5）的几何关系决定阻挡状态。夹角取较小者（θ ≤ 45°），第一象限内 x = d·cosθ、y = d·sinθ，受击圆先与 x 方向边界（距中心 0.5）发生关系：

- **外阻挡**（受击圆与格子无重叠）：d·cosθ − 0.1 > 0.5，即 d·cosθ > 0.6
  - 自然阻挡 d = 0.707 时：cosθ > 0.6/0.707 ≈ 0.8487，θ < 31.9°
  - 距离变短时，cosθ > 0.6/d 的临界角随之变小
- **内阻挡**（受击圆与格子有重叠）：d·cosθ ≤ 0.6；d = 0.6 时受击圆最内点恰在格子边界（0.6 − 0.1 = 0.5），故 d < 0.6 时任何夹角均为内阻挡
- **真·内阻挡**（受击圆完全进入格子）：d·cosθ ≤ 0.4 且 d·sinθ ≤ 0.4；θ ≤ 45° 时约束为 d·cosθ ≤ 0.4，即 d ≤ 0.4/cosθ
  - 距离上限随夹角增大而增大；d = 0.5 时需 cosθ ≤ 0.8，即 θ ≥ 36.87°

## 验证锚点

- 自然阻挡临界角：0.6/0.707 ≈ 0.8487 ≈ cos 31.9°
- 真·内阻挡临界：0.4/0.8 = 0.5，夹角 36.87° 时距离上限恰为 0.5
