## 选择器是什么

所有的索敌都始于选择器。绝大部分选择目标、选择地块、选择单位的行为均由选择器控制：

- **触发选择器**：判定"是否有可选攻击目标"，决定单位是否会进入攻击状态
- **能力选择器**：判定"一个弹道或效果是否能选中某个目标"

其它由选择器控制的行为：溅射效果能否选取某个目标、天赋能否给某个干员上 Buff、技能召唤的召唤物部署在哪个地块。

## 选择器种类

- **自我选择器**：选择自己，无额外参数
- **地块选择器**：选择某一地块，包含地块过滤器、可通行/可部署要求、限定位置等参数
- **所在地块选择器**：选择自己所在格
- **进阶选择器**：最常用，包含仇恨过滤器、阵营、可选性效果的无视与否、无视迷彩与否、是否治疗行为等参数。有多个变体：
  - **阻挡+进阶选择器**：将自身阻挡的目标添加进列表最前，用于"优先选择自己阻挡的目标"
  - **带二次过滤器的进阶选择器**：应用仇恨过滤器后再应用二次过滤器（见下）
  - 其余变体围绕附加筛选条件扩展（指定 tag、Buff、异常效果、生命比例、自身与召唤物范围等）

## 筛选流程

进阶选择器筛出目标按以下顺序：

1. 可选性筛选：隐匿、不可选中、无敌等"无法选择"类效果使目标不可被选中，此类目标被排除
2. 迷彩判定（见下）
3. 仇恨过滤器排序（见《仇恨机制》）
4. 按目标数截取列表前若干个
5. 二次过滤器调整（见下）

## 筛选参数

### 目标阵营

单位的阵营为：我方、敌方、中立。目标阵营参数为：我方、敌方、我方或敌方、中立、全部。选择器仅能选择与目标阵营参数匹配的单位。

绝大多数选择器使用**主观阵营**筛选：目标阵营参数按发起者视角解释（相同阵营指与发起者同阵营，对立阵营指与发起者敌对）：

| 发起者阵营 | 主观阵营 | 可选中的目标 |
|:--|:--|:--|
| 我方 | 相同阵营 | 我方 |
| 敌方 | 相同阵营 | 敌方 |
| 中立 | 相同阵营 | 中立 |
| 我方 | 对立阵营 | 敌方 |
| 敌方 | 对立阵营 | 我方、中立 |
| 中立 | 对立阵营 | 敌方 |

由此，能选择我方单位的敌方单位通常也能选择中立单位。此处的阵营与干员的势力阵营无关。

### 目标行动方式

单位行动方式为：地面、飞行（目前角色类单位均为地面）。目标行动方式参数：仅地面、仅飞行、全部。

### 目标实体类型

单位实体类型为：默认类、装置类、障碍物类（目前敌人类单位均为默认类）。目标实体类型可同时指定多个，匹配其一即可。

### 限制目标数与最大目标数

不限制目标数时，最多能选中 128 个目标（专门配置时可超过）。限制时最多选中最大目标数。选择单个目标的选择器即"限制目标数 + 最大目标数 1"。目标数的处理发生在仇恨过滤器之后。

### 无视迷彩

选择器自行决定是否无视迷彩：

- 触发选择器通常不无视迷彩：即使其能力选择器能无视迷彩，单位也不会选择迷彩单位发动攻击
- 非弹道类型的溅射攻击自动无视迷彩
- 部分能力按参数自动改为无视迷彩
- 具有弹道的选择器按独立参数决定（细节未记录）
- 存在强制无视迷彩的选项

## 迷彩判定

目标带迷彩时，选择器在处理完可选性后进行一次迷彩判定：

1. 选择器无视迷彩或强制无视迷彩 → 可选中
2. 目标具有隐匿免疫（反隐）→ 可选中
3. 其余情况，选择器与目标为敌对关系 → 不可选中

迷彩不属于"无法选择"效果，即使选择器无视"无法选择"，仍可能受迷彩制约。

## 二次过滤器

部分单位在索敌方式之外使用二次过滤器（即现象层所称的“第二优先级”，见《仇恨与索敌》）：在仇恨过滤器之后从头检查列表，符合条件的单位与最前一个不符合条件的单位互换（不做整体排序）。

| ID | 行为 | 范例 |
|:--|:--|:--|
| 0 | 飞行单位优先 | 速射手特性 |
| 1 | 图鉴攻击方式含远程者优先 | 安德切尔 |
| 2 | 拥有指定 tag 者优先 | 格劳克斯 |
| 3 | 拥有指定 Buff 者优先 | 泥岩小队掷能者 |
| 4 | 自身拥有指定 Buff 时，拥有指定 Buff 者优先（存在多对允许的 Buff 时仅需满足其中一对） | “匕现” |
| 5 | 近战优先（细节未记录） | |
