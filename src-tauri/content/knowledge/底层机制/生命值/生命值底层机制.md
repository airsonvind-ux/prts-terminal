## 定位

生命值在内部处理中分为常规生命值、溢出生命值、负生命值三个部分。本条目解析三部分的内部处理规则；非致命伤害（重伤）与生命流失标签见《伤害分类表》。

## 常规生命值

- 拥有 0 的下限与最大生命值的上限
- 最大生命值变化时，生命值同比例变化，保持比例不变
- 各类与生命比例相关的判定均判断常规生命值；拥有溢出/负生命值的单位被获取生命值时，获取的仍是常规生命值的数值与比例

## 溢出生命值

超出最大生命值部分的生命值，表现为覆盖在原血条上、从左侧追加的淡色条。

- 溢出生命值上限与最大生命值相关：巨型敌人固定为 100% 最大生命值；角色类单位默认为 50%，可后续调整
- 仅在应用 modifier 时判定：与常规生命值一同用于生命值扣减（伤害）或储存（追加生命值）
- 不使用 modifier 的生命值调整（如生命恢复）无视溢出生命值判定
- 增加生命值的 modifier 需要携带"溢出部分可产生屏障的治疗"标签才能产生溢出生命值
- 过量治疗的处理通常会临时启用溢出生命值：先调整溢出上限并允许治疗产生溢出，记录溢出量并以生命流失形式扣除，再生成等量的屏障

## 负生命值

生命值"归零"后，在表现上以一段新的"负数血条"（暗红色条，数值实际为正值）参与计算，而非常规生命值降至负数。

- 任何实体类单位都存在与最大生命值相关的负生命值上限，默认 0× 最大生命值（视为未激活），可后续调整；最大生命值变化时负生命值不变化
- 负生命值上限激活时：伤害增加负生命值，追加生命值扣减负生命值，与常规生命值一同计算

### 重设生命值

重设生命值时负生命值机制必然参与判定（无法绕过，但可通过强制属性无视并直接设置常规生命值为 0）：

- 重设目标值大于 0（增加）：
  - 目标值大于当前常规生命值：用负生命值抵消此次部分生命增加，重新计算目标值
  - 否则：仅作用在常规生命值上
- 重设目标值不大于 0（减少/归零）：
  - 当前常规生命值大于 1：负生命值 = 目标值的绝对值 − 当前常规生命值
  - 当前常规生命值不大于 1：负生命值累加目标值的绝对值
- 收尾判定：负生命值达到上限时触发"生命值归 0 前"事件

计算完成后：负生命值被限制在 0 到上限之间（持有不死时上限减 1）；常规生命值被设置（下限为 1）。负生命值等于上限视为生命值归零；负生命值大于 0 时，常规生命值在大多数情况下变为 1。

### 归零与免死

- 负生命值即将超出上限的情形，大部分情况下等价于未激活负生命值时常规生命值即将不高于 0 的情形（触发"生命值归 0 前"事件、判定不死等）
- 但负生命值上限激活时，"生命值归 0 前"事件中无法直接阻止当次生命归零，"成功阻止生命归 0 后"事件通常也无法正常生效
- 免死类效果拆为两个子效果：归零前阻止当次归零；成功阻止后对触发阻止的 Buff 执行附加效果（如消耗该 Buff）。多个免死按第一个子效果的优先级依次触发，单次最多触发一个。持有不死的单位免死通常不触发
