## 版本关系

定乾坤与定乾坤（定本源）是同一关卡的两个难度版本；以下只列与召唤相关的差异。

## 版本差异

| 项目 | 定乾坤 | 定乾坤（定本源） |
|:--|:--|:--|
| 敌方属性 | 无额外倍率 | 攻防血提升至 120%；敛傲、愠怒生命值额外提升至 150% |
| 身形反弹 | 无 | 受到伤害时反弹伤害量 20% 的真实伤害 |
| 朔壳、妄躯技能冷却 | 常规 | 降低至 80% |
| 不赦效果 | 身形sp 每 45 秒召唤一次敌人 | 身形sp 每 45 秒召唤一次敌人 |
| 请君入园·18 追加 | 恍惚的“得意”×12、恍惚的“得意”(晦)×12、山海众司魅人×5、不动的“偷闲”×3、“盛怒”×6 | “碎壁”×6 |
| 朔壳【描躯】循环 | 身形s1×1 → 身形s1×1 → 身形sp×1 | 身形×1 → 身形×1 → 身形sp×1 |
| 朔壳被击倒 | 妄躯×1 | 便符×5（7 组） |
| 妄躯登场 | 身形×2，身形sp×1 | 身形sp×1 |
| 妄躯【筑基】 | 身形×1 | 身形sp×1 |
| 妄躯天赋（每损失 30% 生命） | 身形×2；身形sp×1，身形×1；身形×2 | 身形sp×1，身形×1；身形sp×1，身形×1；身形sp×1，身形×3 |
| 身形sp循环 | 2 段 | 7 段 |

定乾坤中，【晦】属性恍惚的“得意”天赋中的所有倍率失效（变为 100%）。

## 定乾坤

### 朔壳与妄躯

- 朔壳【描躯】：身形s1×1 → 身形s1×1 → 身形sp×1 → 循环。
- 朔壳被击倒：妄躯×1。
- 妄躯登场：身形×2，身形sp×1。
- 妄躯【筑基】：身形×1。
- 妄躯【筑基(天赋)】每损失 30% 生命值，依次召唤：身形×2；身形sp×1，身形×1；身形×2。

### 身形sp循环

所有身形sp共用同一个循环进度，按以下两段循环：

| 段 | 召唤内容 |
|:--|:--|
| 1 | 恍惚的“得意”×1，恍惚的“得意”(晦)×1，恍惚的“得意”×1，恍惚的“得意”(晦)×1，平剑客×1，皮书生×1，皮书生×1，皮书生×1，靳天师×1 |
| 2 | 似兽×1，皮书生×2，皮书生×2，皮书生×2，似兽×1 |

## 定乾坤（定本源）

### 朔壳与妄躯

- 朔壳【描躯】：身形×1 → 身形×1 → 身形sp×1 → 循环。
- 朔壳被击倒：便符×5，共 7 组。
- 妄躯登场：身形sp×1。
- 妄躯【筑基】：身形sp×1。
- 妄躯【筑基(天赋)】每损失 30% 生命值，依次召唤：身形sp×1，身形×1；身形sp×1，身形×1；身形sp×1，身形×3。
