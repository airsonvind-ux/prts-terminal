## 定义

伤判效果是在计算完防御/法术抗性后，增加或减少伤害或直接让伤害归零的一类 Buff 的统称。不包括无敌与重设伤害效果。

## 六类伤判效果

| 类 | 内容 | 备注 |
|:--|:--|:--|
| 伤害修改 | 脆弱、庇护、屏障（屏障量小于伤害时）、敌方的特定条件下伤害减少等 | 屏障按量与伤害的关系分属两类 |
| 过量治疗 | 转化为屏障、溢出伤害（如休谟斯、食腐者权杖） | |
| 抵挡 | 护盾、屏障（屏障量不小于伤害时）、概率伤害抵挡（如星熊） | 早期文本中的"格挡"即抵挡 |
| 闪避 | 次数闪避、概率闪避（如焰尾） | 单从伤害规避角度与抵挡相同，但实际是两种不同效果，在判定条件中区别明显 |
| 不受伤 | 装置的"受到伤害时不受伤"能力 | |
| 反伤 | 反伤天赋（如龙舌兰、玛恩纳） | |

以上效果也存在不作为伤判效果的情况。屏障完全吸收伤害（屏障量不小于伤害）时该次攻击视为被抵挡。

## 处理顺序

伤判效果按事件优先级与 Buff 获取顺序依次处理，事件优先级优先于获取顺序。常见优先级数值见《伤判效果优先级表》。

- 每个伤判效果单独检查自己的条件与效果（血量要求、触发概率、应对伤害类型、屏障量、护盾次数等），条件满足时才可正常规避/增加/减免伤害
- 伤害被某一效果成功归零/取消（成功闪避、成功抵挡、伤害减少至 0）后，一部分伤判效果不再继续处理（检测伤害予以闪避的效果、计次格挡效果），绝大部分效果仍可处理（反伤、受伤计数等）

## 成功造成伤害的判定

- 所有伤判效果处理完且伤害没有归零：本次伤害视为成功造成伤害，可享受"成功造成伤害时"节点的效果
- 伤害在处理完成前归零/取消：根据伤害情况（成功抵挡/成功闪避）触发对应情况的效果

被抵挡或被闪避的伤害不视为成功造成伤害，也不触发以成功受到伤害为条件的效果。

## 无视闪避

具有无视闪避能力的攻击会在处理伤判效果前赋予此次伤害"无法因闪避而取消"的效果。闪避效果的概率、次数等仍会照常判定，但伤害无法被闪避取消。

## 在流程中的位置

伤判效果位于攻击处理流程的第 7 步（On_Take_Damage / On_Take_Heal）拦截判定序列中，在计算完防御/法抗之后、应用 modifier 之前（流程见《伤害底层机制》）。
