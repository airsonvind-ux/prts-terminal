---
title: 集成战略-水月-难度追加条件
brief: 水月肉鸽（水月与深蓝之树）难度追加条件速查：波涛迭起 N1~N18，附浪静风平说明
---

水月主题是集成战略首个采用进阶式扩展难度设计的主题（该设计延续至今）。初始简单难度为"浪静风平"（初始携带【静音小队】藏品）；正式难度名为"波涛迭起"，默认为 N0（无追加条件），更高难度对应"波涛迭起·n"。最初最高难度为 N15，后续更新追加至 N18。难度为累进式（高难度包含低难度全部条件），下表仅列各级新增条件。

敌人难度值列中，N1~N15 攻击与生命同值，N16 起分别标注。

| 难度等级 | 追加条件 | 敌人难度值 |
|:--|:--|:--|
| 波涛迭起·1（N1） | 受到的元素损伤提高 15% | +1 |
| 波涛迭起·2（N2） | 第三层初始随机获得 1 个诅咒收藏品 | +2 |
| 波涛迭起·3（N3） | 所有敌人法术抗性 +10 | +3 |
| 波涛迭起·4（N4） | 招募 3 星及以上干员时希望消耗 +1 | +4 |
| 波涛迭起·5（N5） | 所有领袖单位攻击力和防御力额外 +15% | +5 |
| 波涛迭起·6（N6） | 初始灯火 −15 | +6 |
| 波涛迭起·7（N7） | 所有敌人的移动速度 +15% | +7 |
| 波涛迭起·8（N8） | 受到的元素损伤提高 15% | +8 |
| 波涛迭起·9（N9） | 所有敌人的攻击速度 +15 | +9 |
| 波涛迭起·10（N10） | 初始灯火 −15 | +10 |
| 波涛迭起·11（N11） | 所有精英和领袖单位生命值 +20% | +11 |
| 波涛迭起·12（N12） | 所有敌人法术抗性 +10 | +12 |
| 波涛迭起·13（N13） | 受到的元素损伤提高 15% | +13 |
| 波涛迭起·14（N14） | 可同时部署人数 −1 | +14 |
| 波涛迭起·15（N15） | 所有精英和领袖单位攻击力、防御力和生命值额外 +20% | +15 |
| 波涛迭起·16（N16） | 初始获得收藏品【养育者基因种】且战斗结束后有概率掉落改良基因和改良基因组 | 攻击 +20、生命 +20 |
| 波涛迭起·17（N17） | 组合排异反应将取代基础排异反应 | 攻击 +20、生命 +25 |
| 波涛迭起·18（N18） | 所有精英和领袖单位登场后 20 秒内受到的物理与法术伤害 −50%，攻击力 +30%（受此效果影响的敌人，模型会以红色气息环绕以作提示） | 攻击 +20、生命 +30 |
