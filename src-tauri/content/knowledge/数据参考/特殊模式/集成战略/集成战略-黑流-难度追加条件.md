title: 集成战略-黑流-难度追加条件
brief: 黑流树海难度速查：保密等级 N0~N16 各级追加条件与敌人难度值
---

黑流树海的难度名为「保密等级」，N0 为初始难度（初始生命值上限更高，失败后下次探索获得收藏品「特勤任务影像」；所有敌人最大生命值 -40%、攻击力 -30%，仅限该难度），更高难度为「保密等级·n」，当前最高 N16。难度为累进式，下表只列各级新增与变更；N0~N3 的敌人生命与攻击削减仅限对应难度生效。

| 难度等级 | 追加条件 | 敌人难度值 |
|:--|:--|:--|
| 保密等级·1（N1） | 初始目标生命上限 -2；所有敌人最大生命值 -20%、攻击力 -20%（仅限该难度） | —— |
| 保密等级·2（N2） | 实托邦在区域中生成（1 层 0%、2 层 10%、3 层 15%、4~5 层 20%、6 层 0%）；所有敌人最大生命值 -15%、攻击力 -15%（仅限该难度） | —— |
| 保密等级·3（N3） | 1 个险路尽头节点不再提前揭示；所有敌人最大生命值 -10%、攻击力 -10%（仅限该难度） | —— |
| 保密等级·4（N4） | 出现居民据点节点；失败后不再获得收藏品「特勤任务影像」 | —— |
| 保密等级·5（N5） | 所有敌人最大生命值 +30% | +1 |
| 保密等级·6（N6） | 实托邦效果提升至中期；生成概率变为 1 层 10%、2 层 20%、3~6 层 30%；添加实托邦·方针 | +2 |
| 保密等级·7（N7） | 零件箱初始容量 -2 | +3 |
| 保密等级·8（N8） | 精英及领袖敌人攻击力 +15% | +5 |
| 保密等级·9（N9） | 进入下一区域时损失 10% 源石锭 | +6 |
| 保密等级·10（N10） | 可同时部署人数 -1；初始目标生命上限 -2 | +7 |
| 保密等级·11（N11） | 领袖敌人受到的伤害降低 20% | +8 |
| 保密等级·12（N12） | 实托邦效果提升至晚期；单个实托邦影响范围扩大（x-3）；生成概率变为 1 层 10%、2 层 20%、3~5 层 40%、6 层 30% | +10 |
| 保密等级·13（N13） | 非初始招募五星干员希望 +1；玻利瓦尔，症结之核防御力提升至 150%；未熄之地额外造成攻击力 10% 的灼燃损伤 | +12 |
| 保密等级·14（N14） | 猎犬 proto 进入目标点后行动力 -1；源阶方最大生命值提升至 200%，激活后全场我方每秒流失 100 点生命 | +16 |
| 保密等级·15（N15） | 非初始招募六星干员希望 +1；猎犬 proto 最大生命值提升至 150%，攻击时为卡德霍，黑流之源与痛楚化身回复 1% 最大生命 | +20 |
| 保密等级·16（N16） | 险路尽头不再获得加工品；秘境行商与诡意行商刷新价格 +4 | +25 |

**调查者增益**：

- **多元化展现**：挑战 3~5、6~8、9 或以上难度时，多元奇物类收藏品的效果分别强化为半结构化、非结构化、混沌化
- **生灵的溯游**：挑战 3、6、9 或以上难度且已在生命游戏中点亮对应节点时，分别自动生效对应增益
