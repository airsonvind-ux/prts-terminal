# PRTS 使用说明

## 一、PRTS 是什么

PRTS 是一个跑在你电脑上的明日方舟智能体应用。它专注这一个游戏：

- **能查**：干员、敌人、关卡、数值——来自本地数据库；
- **能算**：伤害、数值、战场推演——靠自带的机制知识库；
- **能动手**：接上 MAA，跑 MAA 支持的各种自动化流程；也能对游戏画面即时截图；
- **能记事**：记得这段对话里发生了什么，也记得工作过程中的重要经验。

它用终端日志的样子跟你说话，带一点无人机的性子——但数字上从不开玩笑。

### 它和普通 AI 有什么不同

**第一，模型的训练记忆有截止时间，游戏却在持续更新。**

所以我们为 PRTS 建了**数据库与知识库**，让这部分信息**可靠、完善、有统一规范**：数据和机制放在本地、随版本维护，需要时现查。

**第二，游戏经验、现象背后的基本逻辑这类隐性知识，检索也补不齐——不知道就是不知道。**

麻烦的地方在于：**模型并不知道自己缺什么。** 它把旧印象当成事实时，自己是察觉不到的；一个错误以"确定"的样子说出来，远比一句"我不确定"危险。

PRTS 的应对是**用幻觉的显化来压制幻觉**：把不确定的地方显形、说出来、标出来，而不是拿一个像样的答案盖过去。查得到的，它去数据库和知识库里查；查不到的，它就说不知道，或者明确标成推测。

这样做，是把判断留给你。PRTS 不做思路构建，只做战术辅助：给你数据、给你推演，也告诉你哪些地方它没有把握。构建思路、拍板的人始终是你。人不会像模型那样"感知不到自己缺什么"，所以它最可靠的纠正者就是你。

被纠正过的错误，它还会记下来，成为自己的一条判断准则，之后一直带在身边。同类问题再出现时，它手里已经有上一次的结论，不必从头再想当然一遍。

**结果是**：回答里"查到的"和"推出来的"是分开的——有出处、能复核，你可以挑着看。

### 附带说几句它想做的事

PRTS 是一个实验型项目。它想解决的错位不难说清：通用大模型和专用领域之间，隔着"信息一直在更新"和"隐性知识学不到"两道沟；而最难看的场面是——用户一眼看出 AI 说错了，AI 却毫不知情。

它按这个领域重新搭了自己的知识来源和判断方式，也带着我的一点偏好：让玩家之间的交流更简单，让更多人真的用得上趁手的工具、把想法落到实处。用的人越多，经验越容易在彼此之间流动，社区也就跟着活跃起来。

"轴"是这条路上已经落地的一步，它服务于交流而不是"抄作业"：现象层直接传播，机制层以引用留在 AI 这一侧，读者不必先啃完机制就能读懂现象。往后还有更远的想法，比如把一个人的游戏理解（某个肉鸽主题下某种打法的运营思路）交给 AI 去"蒸馏"，AI 同时当作者和读者，用户只看现象层。

这些想法还在路上，能走多远，取决于有多少人真的在用它。

## 二、首次使用

第一次打开 PRTS，界面上会陆续出现一些功能说明，帮你认路。这些说明看过一次后就不再出现。

### 先配好模型

PRTS 自己不带模型，它要靠你提供的模型来思考。开始对话之前，先用 **设置 → 模型** 配好三样：

| 填什么 | 说明 |
| :-- | :-- |
| 供应商 | 你手上有哪家的 API，就选哪家 |
| 模型 | PRTS 会拉一次该供应商可用的模型列表，从里面挑一个 |
| API Key | 填这家给你的密钥 |

页面上还有「验证连接」，点一下能立刻知道配得对不对。每个供应商的配置各存各的，互不影响；以后换回某一家，它还是原来的样子。

已保存的 API Key 不会在界面显示明文。点输入框右侧的复制图标，会把密钥写入系统剪贴板，并显示末 4 位供核对。

### 另外两处可以留意

- **设置 → 空间**：PRTS 的工作目录。读、写文件与运行命令默认都在这里发生（读文件本身不受目录限制，见「六、工具与扩展」）。自带一个默认目录，想换成自己习惯的位置也可以；改动从下一轮对话开始生效。
- **设置 → 扩展**：MAA 的连接设置。MAA 是 PRTS 的扩展功能，用不上可以先不管，不影响正常使用。

配好模型就能开始第一段对话了，对话标题会自动生成。

## 三、界面与操作

PRTS 的界面从头到尾只有三个区：顶部功能区、中间的对话区、底部的输入区。

### 顶部功能区

左侧是当前对话的标题，右侧是两个按钮。

| 位置 | 是什么 | 点它会怎样 |
| :-- | :-- | :-- |
| 左侧 | 当前对话的标题 | 打开对话历史：切换对话、给对话改标题、删除对话 |
| 右侧「＋」 | 新建对话 | 开一段全新的对话 |
| 右侧「⚙」 | 设置 | 打开设置页 |

> 对话标题只在有对话时显示。刚安装、还没有任何对话时，左边是空的。

### 对话区

中间这一大片是对话本身。你说的话和 PRTS 的回复按时间排在这里；聊得越久，往上滚得越多。

### 输入区

底部是输入框，所有操作都从这一行开始。

**发消息**

点一下输入框，它的右边就会出现发送按钮。输入内容，点发送；**回车**也是发送，**Shift + Enter** 换行。

**PRTS 正在回答的时候**

- 发送按钮变成「中止」：点它，立刻停下这次回答。
- 你仍然可以打字并发送——这叫**插话**，PRTS 会把你的补充作为新的要求处理；还没排到的插话可以取消。

**上下文进度环**

只要有对话，输入框左边就会出现一个小圆环，代表这段对话已经用了多少上下文（相对于模型能装的总量）。

- **鼠标停上去**：显示当前用的模型信息。
- **点圆环**：出现压缩选项。压缩会把前面的对话收拢，腾出空间继续聊。
- **点圆环上的模型名**：直接跳到设置里的模型页。

## 四、记忆系统

PRTS 有两套记忆，分工不同。

### 成长型记忆：它被教过的东西

这一套记的是**判断**，不是事实。每次被纠正、被要求"记住"、或者在关键结论上被确认过，它都会把这条写成一张成长页。记下的是能改变它以后判断的东西，不是流水账。

成长页是一页一页的，每页由**标题、一句话简介、正文**组成——平时带在身边的只有那句简介，需要时它才展开正文。这些页都归 PRTS 自己打理，你也可以在设置里翻看和修改。

其中有一页是常驻的，叫**「关于博士」**：怎么称呼你、你的习惯和偏好、你习惯怎样一起做事。认识变了它就更新。所以用久了它会越来越对你的路子，不用每次从头介绍自己。

### 经历型记忆：它做过的事情

这一套记的是**过程**，由系统在后台自动完成。

聊过一段之后，后台会把这段时间的对话提炼成一条条工作记录，写着做了什么、进行到哪一步；攒得多了，更早的那些会被压缩成一份梗概。需要的时候，它可以回头检索这些记录，回答"上次那件事到哪了"这类问题。

### 在哪里看

**设置 → 记忆** 里能看到这两套记忆的全貌。你可以新建一页、改掉记错的地方、删掉不要的；经历那边也可以让它整理一次，或者清空。

最后一条边界值得记住：**记忆可以指路，不作依据。** 它记住的东西也可能过时，所以游戏里的事实，它仍然去数据库和知识库里查，而不是凭印象作答。

## 五、知识库与技能

### 知识库：事实与机制放在哪里

PRTS 的游戏知识不是装在模型里的，而是写成条目放在知识库中，分四个领域：

| 领域   | 放什么                            |
| :--- | :----------------------------- |
| 基础概念 | 现象层：伤害、索敌、阻挡、技能、部署这类规则怎么算      |
| 底层机制 | 本质层：现象背后的引擎逻辑，比如一次攻击从发起到结算的事件链 |
| 数据参考 | 查库用的清单：各数据表的字段、枚举与评级映射         |
| 特殊模式 | 游戏内的不同模式，如集成战略                 |

这些条目是有出处的文字，不是模型的印象。你问起机制，它会先定位到相应的条目、按原文来答；问的东西库里没有，它会说出来，而不是编一个听起来合理的答案。

### 技能：教它怎么做事

技能是一套做事的方法，写在文档里，PRTS 在合适的场景自动取用。目前内置五个：

- **数值计算**：查数据、算数值
- **行动推演**：对局面的推演与讨论
- **轴**：把打法整理成文本、读取或解释别人的轴
- **集成战略**：肉鸽里的知识与速查
- **MAA 任务**：通过 MAA 跑自动化流程

**设置 → 技能** 里能看到已装的技能，也能自己安装新的技能或卸载技能。

### 轴：现象层与机制层的分工

轴指广义打法。PRTS 可以把打法写成别人能读懂、能重现的文本，讲的是**怎么做**：写作风格、内容管理，都由打法的创作者定。而 PRTS 的作用在于：背后的底层机制不必在轴里复述，而是只留一个指向。

机制留在库里，轴才能离开作者的手：别人读得懂、能照着做，另一台 PRTS 拿到它也能顺藤摸瓜把机制补齐。PRTS 作为创作与使用之间的桥。

## 六、工具与扩展

PRTS 由模型和它手里的工具组成：模型负责思考与表达，真正动手做事的是工具。工具决定了它能碰到什么、碰不到什么。

### 查数据

干员、敌人、关卡、装置、召唤物、集成战略，本地数据库里有 11 张数据表，另外备了几张速查表：攻击范围、地块、战斗术语、异常效果，还有社区黑话（比如"42"指谁）。

### 推演战场

给它一个关卡和一条路线，它能逐帧模拟敌人的移动，输出每一格发生的事，还能在其中插入额外的阻挡或位移事件。工具直接返回格精度下的事件信息，帧精度下的坐标详情则输出到 log 文件中。

### 读文件、写文件、运行命令

**读文件不受目录限制**，任何位置都能读；**写文件**默认只在工作目录内（位置见「设置 → 空间」），需要写到别处时，它会先向你申请。运行命令以受限身份执行，同样只能写这个目录。

命令执行前的把关在「设置 → 安全」里定，分两档：**询问模式**每次执行前弹确认卡；**自动化模式**下，只有网络访问、安装卸载、进程控制、系统配置、删除这类命令才弹卡，其余直接执行。破坏性的命令无论哪一档都直接拒绝。

### 联网

需要外部信息时，它可以搜索关键词、抓取网页正文。网页只放行公网地址，内网和本机的地址一律拒绝。

### 接 MAA

MAA 是明日方舟的自动化工具。PRTS 可以通过桥来连接已有的 MAA 并完成 MAA 任务：刷关、公招、基建、领奖、肉鸽、抄作业、识别等都可以。

连接在「设置 → 扩展」里配置。PRTS 的 MAA 接口工具目前只支持模拟器，PC 端不行；长任务默认派发出去就返回，不会一直占着对话。

### 看游戏画面

它还能直接截取当前游戏画面，模拟器与 PC 端都可以（PC 端要求游戏窗口没有最小化）。截图是独立的一步，跟有没有接 MAA 无关。

## 七、设置

点右上角的「⚙」打开设置。左边是九个入口，从上到下：应用、模型、安全、空间、技能、记忆、用量、扩展、关于。

设置**没有保存按钮**：改完立刻生效。

| 页面  | 做什么                                               |
| :-- | :------------------------------------------------ |
| 应用  | 窗口置顶开关；关闭 PRTS                                    |
| 模型  | 供应商、模型、API Key（见「二、首次使用」），另有思考强度与 Base URL，以及验证连接 |
| 安全  | 命令执行前要不要问你                                        |
| 空间  | 工作目录的位置，以及这个目录的树状浏览，点开文件会用系统默认程序打开                |
| 技能  | 已装技能清单；安装新技能、移除不需要的                               |
| 记忆  | 两套记忆的概览与编辑（见「四、记忆系统」）                             |
| 用量  | 按对话查看 token 消耗                                    |
| 扩展  | MAA 的连接与增强设置                                      |
| 关于  | 名称与版本                                             |

### 两处值得多说两句

- **模型的思考强度**：用带推理的模型时，这里可以选它思考得多深；普通模型不显示这一项。Base URL 留空就用供应商的默认端点，自己接的服务才需要填。
- **对话跑着的时候**：有些设置会锁住——模型页整页锁，安全页的执行模式、空间页的路径、扩展页的 MAA 设置也锁。原因很直接：这些是这一轮对话正在用的东西，中途换掉会让它前后不一致。技能和记忆只锁写入，查看不受影响。

## 八、常见问题

**配好了模型，还是用不了？**
先点模型页的「验证连接」看能不能通。通不了多半是 API Key 或 Base URL 的问题；模型列表拉不出来，可以用「获取模型列表」手动再试一次。

**MAA 连不上。**
先在「设置 → 扩展」里点自动检测，让它自己找模拟器和 ADB；不行再手动指定路径。另外，PRTS 的 MAA 接口工具目前只支持模拟器，PC 端接不上。

**数据放在哪里？**
对话、记忆、配置都在你自己的电脑上。除了你配置的模型服务，这些内容不会经过别处。

**怎么让它记住一件事？**
直接说就行，比如"记住：我习惯按 1 潜起算"。它会写进成长页，之后一直带着。

**它会不会乱动我的游戏？**
游戏里的操作由 MAA 任务执行，只有你让它跑的时候才发起。具体任务会动到什么，以 MAA 的说明为准。

**对话标题怎么显示的是"新对话"？**
标题由后台生成，生成好之前会先占着这个位置。聊上几句，它就会变成真正的内容。

**我想让它读、写别的文件夹。**
读任何位置都可以，不受限；写默认只在工作目录内，需要写到别处时它会向你申请，你同意就行。

**截图是黑的，或者截不到。**
PC 端要保证游戏窗口没有最小化；模拟器端要确保设备已经挂到 adb 上，第一次调用会多花几秒。
