# 05 工具设计

工具是给**模型**用的界面，不是给人用的 API。模型只看得到三样东西：名字、
描述、参数 schema。描述写不清，它就不会用；参数收得太宽，它就会乱填。

## 名字

`initialize` 里报的名字**不带前缀**，宿主拼成 `<id 派生前缀>_<名字>`：

```text
插件 hello-python（id）
工具 hello            → 模型看到 hello_python_hello
```

约定：

- 全小写、下划线分词，动词开头：`search_operator`、`read_note`、`export_team`；
- 不要重复插件名（`hello_hello` 很难看）；
- 别用 `run`、`do`、`call` 这种没有信息量的词；
- 最终名字必须匹配 `^[a-z][a-z0-9_]{0,63}$`，不合法整个插件加载失败。

## 描述

一到三句，回答三个问题：

1. **做什么**：一句话说清动作与对象；
2. **什么时候用**：给模型一个判断依据；
3. **返回什么**：文本还是结构化数据，大概长什么样。

好的写法：

```text
按名字查一位干员的职业、稀有度与技能。用户提到具体干员、
需要确认ta的定位时使用。返回一段简短文本，不是 JSON。
```

差的写法：

- 「查询数据」——查什么数据？
- 「强大的干员查询工具」——形容词对模型没有信息量；
- 把参数说明重复一遍——参数已经有 schema 了。

## 参数

`parameters` 是标准 JSON Schema 对象：

```json
{
  "type": "object",
  "properties": {
    "name": { "type": "string", "description": "干员名，中文或英文" },
    "server": { "type": "string", "enum": ["cn", "bilibili"], "description": "默认 cn" }
  },
  "required": ["name"]
}
```

几条经验：

- **参数越少越好**。超过五六个，模型填错的概率直线上升；
- 枚举优于自由字符串——`enum` 是给模型的强提示；
- `required` 只放真正必需的；其余在 `description` 里写默认值；
- 参数名用 snake_case，和工具名一致；
- 别让模型传 JSON 字符串再自己解析（`"args": "{\"a\":1}"`），那是双重转义。

## 返回值

`result` 会变成模型看到的工具输出，**原样**进上下文。

- 返回**字符串**最省心：一段话，两三行以内；
- 返回对象也行，宿主会序列化成 JSON 给模型——但要有节制，几十 KB 的 JSON
  既烧上下文又难读；
- 不要在返回值里塞调试信息、时间戳、内部 id；
- 结果为空要说清「没有找到」，不要返回空串——模型会以为工具坏了；
- **截断必须说明**。你自己定了上限（最多 40 条、最多 2000 字），超了就要在
  末尾写一句「还有 12 条没列，缩小范围后再问」。静默截断最难查：模型会拿半份
  数据下结论，而且它不知道自己只看到了半份。

## 出错时

分两类，别混：

| 情况 | 怎么做 |
|---|---|
| 用户层面的失败（没查到、参数不合业务规则） | 返回**正常结果**，用一句话说明，例如 `没有找到叫「能天使」的干员，可能名字不完整。` |
| 协议或宿主层面的故障（不认识的工具名、缺参数） | 回 JSON-RPC error，`-32602` |

第一种模型能读懂并换个说法重试；第二种是程序错误，报错更合适。

## 超时与长任务

工具定义里可以给 `timeoutMs`，默认 60000。超过时限宿主会发 `cancel`，2 秒
没回音就杀进程并标记故障。

需要跑很久的事，拆成两个工具：一个「开始」，立刻返回任务 id；一个「查询」，
按 id 取进展。别在一个 `tool.call` 里同步等十分钟。

## 并发

宿主可能同时调用你的多个工具。你的实现要么能并发处理，要么在内部排队——
但**不要**让读线程停下来等某一次工具执行完，否则 `host.call` 也会被堵住。

## 一个完整例子

```json
{
  "name": "search_operator",
  "description": "按名字查干员的职业、稀有度与技能。用户提到具体干员时使用。返回一段简短文本。",
  "parameters": {
    "type": "object",
    "properties": {
      "name": { "type": "string", "description": "干员名，中文或英文" }
    },
    "required": ["name"]
  },
  "timeoutMs": 10000
}
```
