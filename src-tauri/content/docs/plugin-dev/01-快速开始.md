# 01 快速开始

两个目标读者各一遍：写 Python 的、写 Rust 的。走完都能在对话里看到插件
提供的工具被调用。

前置：应用已安装并能正常打开对话；`plugin_check` 与模板在开发包里。

## 路线 A：Python（五分钟）

### 1. 建一个文件夹

```text
hello-python/
├─ plugin.json
└─ hello.py
```

把模板 `python-hello` 里的两个文件拷进来，或者自己按下文写。

`plugin.json`：

```json
{
  "manifestVersion": 1,
  "id": "hello-python",
  "name": "Python 示例",
  "version": "0.1.0",
  "kind": "process",
  "entry": { "exe": "python", "args": ["hello.py"], "transport": "stdio" },
  "requires": { "protocol": 1 }
}
```

`hello.py` 直接复制模板里的那份——它已经实现了握手、一个 `hello` 工具、
以及 `shutdown` 收场。想改就从那里改。

### 2. 先让校验器过一遍

```bash
plugin_check ./hello-python
```

八项全 PASS 才算能装。任何一项 FAIL，输出里第二行是原因、第三行是改法；
对照 [09-排错](09-排错.md)。

### 3. 装进应用

设置 → 扩展 → 安装（或把文件夹拖进列表区域）。确认卡片上显示的名字、
版本、能力都对，点安装。

装好后列表里会出现这行，开关默认打开。新建一个对话，说一句「用 hello 工具
跟我打个招呼」，模型应当调用 `hello_python_hello` 并显示「你好，世界！」。

## 路线 B：Rust（十分钟）

### 1. 建工程

把模板 `rust-hello` 整个目录拷出来，改 `plugin.json` 的 `id` 与 `name`。

### 2. 构建，把产物放到插件目录

模板的 README 里有一行构建命令；跑完把产物（`hello.exe`）拷到 `plugin.json`
旁边——**入口是插件目录里的文件**，不是构建目录里的。

非 Windows 平台记得把 `entry.exe` 改成没有后缀的名字。

### 3. 校验、安装、试用

同路线 A 的第 2、3 步。

## 调用成功是什么样

对话里会出现一条工具调用记录：工具名带插件前缀（`hello_python_hello`），
下面是工具返回的文本。返回文本就是你在代码里写的那句话——插件不控制渲染。

## 改不动的时候

- 校验器第 3 项 FAIL：入口写错。Python 看 PATH 里有没有 `python`，Rust 看
  exe 是不是就在 `plugin.json` 旁边；
- 装上了但工具没出现：看列表这行的状态与原因，`加载失败` 会把 manifest 的
  问题直接写出来；
- 对话里调用报「已停用」：这个插件被关掉了，或者旧对话用的是旧快照——新建
  一个对话。
