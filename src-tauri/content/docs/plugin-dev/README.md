# PRTS 插件开发手册

插件是一段**独立进程**，通过标准输入输出与 PRTS 说话。它给模型提供工具，
也可以附带技能（提示词片段）。插件崩溃不会拖垮应用，停用插件不用重启。

## 外部开发者只有一条路：process

`plugin.json` 里的 `kind` 有两种取值：

| kind | 谁能用 | 说明 |
|---|---|---|
| `process` | 所有人 | 独立进程，本手册讲的就是它 |
| `builtin` | 仅应用内置 | 编译进应用、随版本发布。列出来只是让你看懂内置插件是怎么声明的 |

你写的插件永远是 `process`。

## 一个插件长什么样

```text
my-plugin/
├─ plugin.json     声明：id、名字、版本、入口、能力
├─ hello.py        你的程序（Rust 就是编译出来的 exe）
└─ skills/         可选：附带的技能
   └─ 看图/
      └─ SKILL.md
```

`plugin.json` 最小可用版本：

```json
{
  "manifestVersion": 1,
  "id": "my-plugin",
  "name": "我的插件",
  "version": "0.1.0",
  "kind": "process",
  "entry": { "exe": "python", "args": ["hello.py"], "transport": "stdio" },
  "requires": { "protocol": 1 }
}
```

## 它能做什么

- **提供工具**：模型在对话里调用，参数与返回值都由你定；
- **画一张视图**：工具返回 `{content, view}`，文字进上下文、卡片给人看；
- **读宿主数据**：只读查询干员、关卡、敌人、材料（`query.call`）；
- **读写自己的目录**：私有数据与临时文件（`fs.plugin`、`fs.temp`）；
- **附带技能**：一段提示词，让模型知道「什么时候该用这个插件」。

它**不能**做的事：直接访问应用的内部状态、调用别的插件的工具、读写插件目录
以外的文件。能力要逐条声明，没声明的调用会被拒绝。

## 三件套

| 东西 | 用途 |
|---|---|
| `plugin_check` | 在你自己的机器上跑一遍八项检查，全 PASS 再往应用里装 |
| 模板 | `rust-hello` / `python-hello`，都是「一次握手 + 一个工具」 |
| 本手册 | 从装第一个插件到发布 |
