---
title: 集成战略-傀影-难度追加条件
brief: 傀影肉鸽（傀影与猩红孤钻）难度追加条件速查：正式调查 N1~N15，附古堡观光说明
---

傀影的正式难度名为"正式调查"，默认为 N0（无追加条件）；更高难度对应"正式调查·n"。难度为累进式（高难度包含低难度全部条件），下表仅列各级新增与变更。另有"古堡观光"难度，初始携带【静音小队】藏品。

| 难度等级 | 追加条件 |
|:--|:--|
| 正式调查·1（N1） | 古堡中会出现幻觉 |
| 正式调查·2（N2） | 可能同时出现 2 种幻觉 |
| 正式调查·3（N3） | 初始随机获得一份剧作家手稿和一个正面效果收藏品 |
| 正式调查·4（N4） | 初始改为随机获得一个负面效果收藏品（为非重铸/剧作家手稿的【普通·荣耀之证】收藏品）和一个正面效果收藏品 |
| 正式调查·5（N5） | 所有精英和领袖敌人的生命值 +20% |
| 正式调查·6（N6） | 古堡中会上演猩红剧目 |
| 正式调查·7（N7） | 进入《故土残躯》时，随机获得一份剧作家手稿 |
| 正式调查·8（N8） | 古堡中出现了新的幻觉（狂乱、焦虑、痴愚、颓废，幻觉症状将加入探索之中）；同时出现 2 种幻觉的概率提升 |
| 正式调查·9（N9） | 在《噩梦之始》及后续区域招募 6 星干员时希望消耗 +1 |
| 正式调查·10（N10） | 紧急作战和险路恶敌中，敌人的攻击力和生命 +15%（该加成实际不生效）；使探索走向不同结局的事件出现概率大幅提升 |
| 正式调查·11（N11） | 出现特定幻觉组合时，会触发幻觉融合效果 |
| 正式调查·12（N12） | 结局战斗的难度提升（Ⅲ层的险路恶敌领袖敌人将加入结局战斗之中：迷路的巨像加入卢西恩，"猩红血钻"的战斗；喷气人加入伤心的大锁的战斗；漂泊颂偶加入"剧团喉舌"的战斗；"雪牝"&"霜牡"加入"剧作家"的战斗） |
| 正式调查·13（N13） | 初始改为随机获得一个重铸的负面效果收藏品和一个正面效果收藏品 |
| 正式调查·14（N14） | 所有精英和领袖单位登场后 20 秒内受到的物理与法术伤害 −50%，攻击力 +30%（受此效果影响的敌人，模型会以红色气息环绕以作提示） |
| 正式调查·15（N15） | 进入《血月长廊》时，随机获得一个负面效果收藏品（为非重铸/剧作家手稿的【普通·荣耀之证】收藏品）和一个特殊的正面效果收藏品（该正面收藏品为价值 16 源石锭的高稀有度收藏品） |
