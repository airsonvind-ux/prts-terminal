---
title: 集成战略-界园-难度追加条件
brief: 界园肉鸽（岁的界园志异）难度追加条件速查：请君入园 N1~N18
---

界园主题的难度名为"请君入园"，默认为 N0（初始生命值上限更高，岁兽残识中的敌人极为虚弱（最大生命值×0.5，攻击力×0.75（效果叠乘））；所有敌人最大生命值-20%，攻击力-20%（仅限该难度）），更高难度对应"请君入园·n"，最高 N18。难度为累进式（高难度包含低难度全部条件），下表仅列各级新增与变更。

本主题难度增益（挑战达到相应等级时获得额外增益）：

| 难度等级 | 追加条件 |
|:--|:--|
| 请君入园·1（N1） | 初始目标生命上限-2，所有敌人最大生命值-10%，攻击力-10%（仅限该难度） |
| 请君入园·2（N2） | 岁时的影响更加强大 |
| 请君入园·3（N3） | 初始钱盒加入3枚大炎通宝，这在降低原有随盒赠钱投出几率的同时，也使得钱盒的通宝容量+3（7→10） |
| 请君入园·4（N4） | 便符与受符的生命值+50%，其余所有敌人的生命值+40%（不包括职业为装置的敌方单位） |
| 请君入园·5（N5） | 所有敌人受到物理和法术伤害降低10％（不包括职业为装置的敌方单位） |
| 请君入园·6（N6） | 岁时效果从朦胧提升至真切 |
| 请君入园·7（N7） | 初始钱盒中的大炎通宝替换为特殊厉钱（共四枚：西廉贞、北刺面、南见山、东缺角），岁兽残识中的敌人不再虚弱 |
| 请君入园·8（N8） | 招募五星干员希望消耗+1，精英和领袖敌人防御力、生命值+20% |
| 请君入园·9（N9） | 岁兽残识中的作战最低数量增加，可同时部署人数-1 |
| 请君入园·10（N10） | 受符的干员攻击力-50%，初始目标生命上限-2 |
| 请君入园·11（N11） | 可留存的招募券数量-2，所有敌人的攻击力+20%（不包括职业为装置的敌人） |
| 请君入园·12（N12） | 岁时的效果从真切提升至入髓，刷新商店和重新投钱基础消耗票券+1 |
| 请君入园·13（N13） | 雕伥的最大生命值+50%（与厉-安硕鼷加算叠加），“易”切换晦明状态后获得的屏障提升至150% |
| 请君入园·14（N14） | 领袖敌人受到伤害在请君入园·5的基础上改为降低20％，“岁”、“岁躯”的攻击力提升至150%，遭到“岁”、“岁躯”拍击并退场的干员，再部署时间提升至90秒 |
| 请君入园·15（N15） | 招募六星干员希望消耗+1，受符的效果半径+0.8，并在每次造成伤害时额外造成一次攻击力20%的灼燃损伤，“瑕”的攻击力和生命值+50% |
| 请君入园·16（N16） | 所有敌人攻击速度+20，“后兽”的生命值提升至200%，“矩兽”的攻击力提升至200%，“后兽”召唤的敌人有所不同（详见对应关卡情报） |
| 请君入园·17（N17） | 领袖敌人攻击力+20%，指点迷津中招募及进阶干员减少希望变为1，【醉生】/【谋炎】在待部署区添加的宿傲/宿怒数量+1，“敛傲”“愠怒”的攻击力提升至200% |
| 请君入园·18（N18） | 重新投钱会消耗更多的票券（从第1次主动投钱开始，依次为：1、2、2、4、6、9、9、9……），部分特殊作战，以及从第四层开始的普通战斗、紧急作战与险路恶敌出现额外的敌人，“朔壳”闪避所有非自身阻挡单位的物理与法术伤害 |
