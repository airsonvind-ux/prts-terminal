## 字段清单

- 身份：敌人ID、名称、级别、描述、地位、种类、关联敌人
- 行动与战斗：攻击方式、伤害类型、行动方式、攻击半径、攻击速度、攻击间隔、移动速度、能力列表、天赋文本、技能文本
- 属性：最大生命值、攻击力、防御力、法术抗性、生命自回速度、重量、基础嘲讽等级、损伤抗性、元素抗性
- 抗性：异常抗性
- 计数：目标价值、不计入敌人总数、numOfExtraDrops、viewRadius
- 其他：备注

## 取值含义

- **级别**：0/1/2，0 为基础版本。同一敌人 ID 的不同级别各自为一行
- **地位**：普通 / 精英 / 领袖
- **种类**：12 种固定取值：感染生物、无人机、萨卡兹、宿主、海怪、法术造物、源石造物、化物、机械、野生动物、坍缩体、其他。其中"其他"对应表中的空值
- **攻击方式**：近战 / 远程 / 不攻击 / ALL（ALL 表示近战、远程均可）
- **伤害类型**：物理 / 法术 / 治疗 / 无，可多个
- **行动方式**：地面 / 飞行
- **能力列表**：游戏内图鉴的能力文本，表述简洁
- **天赋文本**：能力详细描述，来源于 Wiki 页面
- **技能文本**：格式化的技能信息，来源于 Wiki 页面
- **重量**：参与位移力度判定，详见《力度与位移》
- **异常抗性**：免疫的异常状态集合（晕眩、沉默、沉睡、冻结、浮空、战栗、恐惧、诱导、麻痹、传送、缚地）
- **损伤抗性**：绝大多数敌人均为 0
- **元素抗性**：绝大多数敌人均为 0
- **目标价值**：敌人进入保护目标后扣除的关卡生命值
- **不计入敌人总数**：1 表示特殊敌人（额外召唤、演出型、友好单位等），不计入关卡敌人总数
- **numOfExtraDrops**：斗蛐蛐（争锋频道）中该敌人的单兵基础费用，每派出第一个该兵种选手时扣除
- **viewRadius**：斗蛐蛐（争锋频道）中该敌人的单兵附加费用，同兵种每多出战一人按此数累计增加扣费
