## 规则

- 每名干员持有一件战术装备，效果只在保全派驻中生效。
- 同一职业（非分支）的战术装备效果相同；携带该职业的干员数量决定该职业装备在卡组中的占比。
- 默认开放 A 型；通关任一区域的所有阶段后可切换 B 型。
- 装备之间的数值加算；装备与干员技能、天赋的数值乘算。
- 一名干员的战术装备上限为 5 件。
- 部署时触发的装备效果不能被接力继承。

## 效果

| 职业 | A 型 | B 型 |
|---|---|---|
| 先锋 | 使接力干员获得先锋装备：攻击力 +20%，每 3 秒获得 1 点技力 | 部署时触发：将所有战术装备转换为调用凭证（10 张/件） |
| 近卫 | 使接力干员获得近卫装备：攻击力 +40% | 使接力干员获得近卫装备：攻击力 +20%、攻击速度 +20 |
| 重装 | 使接力干员获得重装装备：防御力 +40%、阻挡数 +1 | 使接力干员获得重装装备：最大生命值 +25%、防御力 +25% |
| 狙击 | 使接力干员获得狙击装备：攻击速度 +40 | 使接力干员获得狙击装备：最大生命值 +25%、攻击力 +25% |
| 术师 | 使接力干员获得术师装备：攻击力 +20%，每 3 秒获得 1 点技力 | 使接力干员获得术师装备：攻击力 +40% |
| 医疗 | 使接力干员获得医疗装备：全场所有友方单位受到的物理与法术伤害减少 10% | 部署时触发：使攻击范围内一名重伤倒地的干员复活（会触发部分部署时生效的战术装备效果） |
| 辅助 | 部署时触发：获得 15 张调用凭证 | 部署时触发：从预备区随机检视四名干员，选择一名调度 |
| 特种 | 部署时触发：使撤退干员直接返回待部署区，再部署时间 -50% | 使接力干员获得特种装备：攻击速度 +20，每 3 秒获得 1 点技力 |
