## 一、移动判定框架（每帧）

三类坐标（实体/光标/足坐标）、理论移速（= 属性移速 × moveMultiplier）等基础量定义见《敌人行动与移动机制》，本文直接使用。

**前提**：状态机处于 MOVE 状态时每帧判定移动。MOVE 覆盖：自主移动、检查点停驻、束缚罚站；不覆盖：失衡位移、阻挡偏移、闪现、传送。

**步长**：每帧位移 = 本帧速度 × (1/30)；速度由加速度驱动从 0 逼近理论移速（公式见第四节），稳态后每帧位移 = 理论移速 ÷ 30。速度上限 = 理论移速，不因接近目标而减速；剩余距离小于步长时仍按步长移动（可能越过目标点），完成判定由检查点半径收尾。位移计算本身不检测落点是否可通行（落点修正见步骤 5）。

**每帧移动判定步骤**：

- **0**：实体坐标在有效地图外 → 直接以理论移速向地图内移动，跳过其余步骤
- **1**：根据光标坐标 + 寻路地图确定下一个目标
- **1.5**：本帧以理论移速可到达目标 → 直接设置光标坐标 = 目标，跳过其余步骤（本质 = 防越过目标点的分支，与步长规则一体；仅理论移速 > 1.5、属性移速 > 3.0 时可能出现，因移动类检查点完成半径 0.05）
- **2**：获取给定方向（长度 1 向量或 0）
- **2.5**：束缚 → 本帧位移 = 0，跳到步骤 5
- **3**：计算避障力向量
- **4**：计算本帧加速度、本帧速度（存入惯性向量）、本帧位移
- **5**：实体坐标 + 位移 = 目的地；若跨地块且目的地不可通行 → 执行修正；随后实体坐标 = 目的地

## 二、方向与目标

- **目标**：光标所在地块 nextNode 的地块中心；该 nextNode 即目标地块时，目标 = 目标点（含偏移）。偏移只在最后一跳生效，行走途中偏移不参与方向计算
- **给定方向**：先判定当前检查点是否完成，完成则切换至下一检查点，直到当前检查点未完成；然后：当前检查点非移动类 → 方向 0；移动类/终点 → 光标到目标的单位向量；光标在不可通行地块或无路线 → 方向 0
- 备注：visitEveryTileCenter / visitEveryNodeCenter / visitEveryNodeStably 为可选走位配置：启用时敌人依次经过各地块/节点中心走位（带缓冲与已过标记），而非沿 nextNode 直线斜走；PRTS 现有数据均未启用

## 三、避障力（每 3 寻路帧计算一次，一次应用 3 帧）

**一句话结论**：避障力是卡墙/贴墙时的安全网。正常寻路行进沿格中线走，足坐标距边界 ≥ 0.3，任何方向不触发，路线完全不受相邻障碍物影响。

**最近点定义**（仅本节内使用）：以足坐标为中心、左右方向长 0.4 的线段（左右各 halfBodyWidth，不同敌人可调，默认 0.2）；线段左端点/中点/右端点分别是左列/本列/右列地块的最近点。

**更新机制**：每 3 个寻路帧计算一次，结果缓存应用 3 帧。阻挡状态、攻击状态等非寻路帧不更新避障力的判定位置，不影响后续路线；但坐标改变（如阻挡偏移）会改变下次采样的判定位置，使避障方向随之调整。

**冻结时序**：阻挡/受控期间避障周期完全冻结（周期计数暂停），解除后从冻结值继续。例：敌人在周期第 0 帧被阻挡，解除后下一寻路帧为周期第 1 帧——等价于在周期第 0 帧与第 1 帧之间插入一段静止；期间坐标不变则后续路径完全不变，坐标改变（阻挡偏移）则相当于在该处插入一次坐标调整，路径自此分叉。

**周期起点**：常规认识是避障周期从出生帧的下一帧开始计数；实际表现可能出现偏差，因此采用等效避障相位作为可调整参数，精确计算前先校准出生帧与避障首帧。

**触发条件**（影响路线需全部满足）：

1. 最近点进入障碍物边界 0.25 内（距离边界 < 0.25），或光标已在不可通行地块
2. 推离方向与给定方向不共线。共线（前后方障碍）→ 避障力 = 0
3. 非束缚 MOVE

**计算链**（光标在可通行格；周围 8 格中不可通行/障碍物且在地图内的地块）：

1. 地块相对坐标 = 障碍物中心 − 中心地块中心
2. 接近偏移 = (最近点 − 中心地块中心) 逐分量乘 地块相对坐标，与 0 取最大（直观：最近点相对中心、在障碍方向上的正向偏移）
3. 有效偏移量 = (接近偏移 − 0.25) × |地块相对坐标|，仅在相对坐标非 0 的方向有效（如正右边地块的 y 值恒为 0）；越大说明最近点距该障碍物越近
4. 推离向量：4 边（相对坐标单分量非 0）且有效偏移量有 1 项 > 0 → −有效偏移量 × 相对坐标；4 角（双分量非 0）且 2 项均 > 0 → −(两项平均) × 相对坐标；否则 0

随后：累加 8 格推离 → 零向量则 a = 零，否则标准化为单位向量 a。**避障力 = a − a 在给定方向上的投影**。

**触发边界表**（实体相对中心地块偏移，越过即触发；与计算链推导一致）：

| 障碍物方位 | 触发条件 |
|---|---|
| 正上方 | y > 0.45 |
| 正下方 | y < −0.05 |
| 正左 / 正右 | x < −0.05 / x > 0.05 |
| 对角 | 双条件（右上：x > 0.05 且 y > 0.45） |

**性质**：

- 开关式：不触发则全链为零；触发后 a 为单位向量，实际避障力 = 单位向量 × max(惯性/移速, 0.5)，最小为 0.5
- 前方障碍不靠避障：寻路已规避（nextNode 不指向不可通行格），碰撞修正是外力推离路线后的兜底
- 光标在不可通行地块：a = 该格中心 → 周围 8 格最近可通行格中心（等距正上优先、顺时针递减），随后同投影规则

## 四、惯性与修正

- **惯性向量** = 上帧实际速度向量；仅非束缚 MOVE 状态更新，阻挡/晕眩/位移/束缚期间冻结（造成"解除阻挡后敌人入坑"等现象）
- **停驻滑行**：移动类检查点完成、切换到停驻类（WAIT）检查点后，状态机仍处 MOVE 状态，每帧移动判定照常执行，但给定方向 = 0。惯性向量不因检查点切换而清零，仍为上一帧实际速度，加速度 = −惯性×steeringFactor（无避障时），速度按几何级数衰减；滑行与停驻计时并行。若停驻时间不足以让速度衰减到 0，残余速度作为下一段 MOVE 的初始惯性。与束缚罚站的区别：束缚时位移 = 0、惯性冻结（硬停）；停驻是方向 0 的自由衰减（滑停）
- **实际避障力** = 避障力 × max(惯性向量大小 / 理论移速, 0.5)，最小为避障力的 50%
- **加速度** = ClampMagnitude((给定方向×理论移速 − 惯性向量)×steeringFactor + 实际避障力, maxSteeringForce)；steeringFactor / maxSteeringForce：地面 8/10、飞行 20/100、关卡未开启 Steering 100/100（存在特例，如托生莲座、近地悬浮敌人取8/10）
- **本帧速度** = ClampMagnitude(加速度×(1/30) + 惯性向量, 理论移速)；速度上限 = 理论移速；速度存回惯性向量
- **本帧位移** = 速度 × (1/30)
- **加速/刹车距离估算**：速度差/速度按等比数列衰减（公比 = 1−steeringFactor/30，参数见上文），用等比数列求和可快速估算加速损失与刹车滑行距离（地面 ≈ 2.75 倍稳态帧位移、空中 ≈ 0.5 倍），免去逐帧计算，用于快速估计敌人行进时间；加速到 95% 全速约 9.7 帧（地面）
- **碰撞修正**（判定步骤 5）：位移前后实体坐标处于不同地块且进入地块不可通行 → 修正后位移 = 位移 − 2×投影（投影 = 位移在"实体坐标到该不可通行地块方向"上的投影）；正面冲入被弹出，斜角擦入可行
- **推论（避障移出速度）**：避障时给定方向 0，加速度 = −惯性×8 + 实际避障力；平衡时惯性 = 实际避障力/8；基础避障力为标准化的单位向量（大小 1）、max 取下限 0.5 → 实际避障力 0.5 → 惯性 = 0.5/8 = **0.0625 格/s**

## 五、检查点与终点判定（每帧）

- 检查点/终点判定是独立于移动判定的每帧循环（与移动同帧时在移动后执行），非 MOVE 状态（罚站/被控等）同样执行
- 每帧更新当前检查点状态 → 判断是否满足完成条件 → 满足则切换至下一检查点；判定只针对当前检查点，不能靠推敌人到下一检查点位置跳检查点
- **卡墙跳检查点**：移动类检查点期间光标进入不可通行地块（无法通往目标点）→ 直接判定该检查点完成
- 检查点判定/更新后是终点判定：光标进入终点 0.05 半径内即抵达
- 各类型检查点的完成条件口径见《敌人行动与移动机制》，类型清单见《行动指令类型枚举》
- 配置：visitEveryCheckPoint = true 时须完成全部检查点才算抵达；ignoreAllButMoveCp 忽略全部非移动检查点（用于直接冲家的敌人）
