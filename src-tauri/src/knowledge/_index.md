# PRTS 知识库索引

本索引描述知识库结构。条目内容由 read_knowledge 工具按条目名读取。

## 四大领域

- **基础概念**：现象层，概念与现象的描述
- **底层机制**：本质层，现象背后的引擎实现与精确计算规则
- **数据参考**：查库参考，数据库表字段清单、枚举评级表与模式数值表
- **特殊模式**：各常驻与限时玩法的机制条目
