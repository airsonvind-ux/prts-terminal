# PRTS 知识库索引

本索引描述知识库结构。条目内容由 read_knowledge 工具按条目名读取。

## 四大领域

- **基础概念**：现象层，概念与现象的描述
- **底层机制**：本质层，现象背后的引擎实现与精确计算规则
- **数据参考**：查库参考，数据库表字段清单与枚举评级表
- **特殊模式**：集成战略模式

| 领域 | 简介 |
|:--|:--|
| 伤害 | 伤害、治疗与攻速的计算规则，伤害数值的显示与判定 |
| Buff与状态 | Buff 的叠加与目标管理，异常效果与抵抗 |

| 移动与阻挡 | 敌人行动与位移（自主移动、推拉、诱发），阻挡判定与阻挡偏移 |
| 属性 | 属性数值的计算规则与修改来源 |
| 干员 | 干员养成系统与职业分支定位 |
| 技能 | 技力回复、触发条件与特殊属性 |

| 敌人 | 敌人分类维度与属性评级 |
