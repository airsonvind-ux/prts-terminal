## 攻击范围

几乎每个单位的每个攻击能力/技能能力都有一个攻击范围碰撞体：

- 多边形：1×1 方块拼凑，按单位数据中的“攻击范围 ID”自动生成（干员常用；各 ID 的具体范围以攻击范围查询工具为准）
- 圆形：写死的攻击范围半径（通常为 1）

按用途分为青色（治疗相关）与橙色（攻击相关），区别在点选时的条纹遮罩颜色。条纹显示始终以格为单位，圆形范围也显示为方形条纹。巨型 Boss 的红色条纹不属于攻击范围。
关于如何干员与敌人的受击范围，可以参考《阻挡与受击判定》中的受击判定部分

### 可拉伸

部分攻击范围受“攻击距离”属性影响（可拉伸）：

- 多边形：每 1 点攻击距离向正前方拉伸 1 格，重叠部分无效，相当于前方多一列
- 圆形：半径增加等同于攻击距离的量
- 不可拉伸：无论多边形还是圆形，始终不受攻击距离影响

## 视野范围

单位除攻击范围碰撞体外，还有一套以地块为单位的视野范围（AttackRangeTiles）。

视野范围 =（人为规定的显示范围 || 攻击触发器的范围）+ 额外范围，其中逻辑或表示优先顺序：显示范围 > 触发器范围。

攻击触发器（"默认范围"）类型：

| 类型 | 行为 |
|:--|:--|
| SelectorTrigger | 范围内有目标则触发攻击/治疗 |
| NeverTrigger | 永不触发攻击，范围恒为 0 |
| AlwaysTrigger | 总是攻击，范围恒为 1（全屏） |
| 其他 | |

通常视野范围与攻击范围一致，但开启技能等可改变视野范围使两者出现差异：

- 人为规定的显示范围不改变攻击范围本身（安比尔“雷达定位”可攻击全场，点选时攻击范围无变化）
- 永不触发攻击的技能使单位丢失全部视野范围（铃兰“狐火渺然”、澄闪“澄净闪耀”），所在格也失去斜条
- 确认方式：选中干员的橙色斜条格

技能范围不一定等于攻击范围：瞬发和目标选取型技能的技能范围是目标的选取范围，而非攻击范围扩大。

视野范围系统用于生息演算的“迷雾”机制与第十二章的“鉴定”机制（长夜临光的“视野”不使用此系统）。

## 盲区与有效视野

以树丛、盾与墙、旧日之火为代表的遮挡视野装置，效果为令角色获得盲区。

- 判定：单位所在格与各地块中心逐一连线（连线细节存疑），任一连线穿过存在遮挡视野单位的地块（忽略目的地地块）则该地块记为盲区；遮挡装置数量增减时所有单位盲区立刻更新
- 我方单位无法主动选择盲区中的单位作为攻击/能力目标（类似反向迷彩）；点选后攻击范围内的盲区地块标记为灰色
- 盲区不改变视野范围本身，除挽歌燃烧殆尽本身机制外，不影响其他视野范围相关机制

不直接选择目标的能力可绕过盲区：光环效果（逻各斯“殁亡”、铃兰“狐火渺然”）、特殊弹道（魔王“明日遥远不及”微尘）、强行指定单位（凯尔希选择 Mon3tr、远牙“同盟支援”）、不进行来源结算的效果（炼金单元）。复合技能分别判定各能力（塞雷娅“钙质化”减速/增伤生效，但攻击/治疗受阻）。

利用其他单位攻击范围或视野范围的能力，依照自己的盲区而非对方的盲区判定：召唤物按召唤者攻击范围攻击时只看召唤者盲区；选取目标由谁进行，就只看谁的盲区。

有效视野：角色类单位 = 视野范围 − 盲区的剩余地块；环境 = 所有角色类单位有效视野之和。挽歌燃烧殆尽中所有“攻击范围”或“视野”描述均指有效视野总和。铁钳号·原型机不获得盲区机制，但仍能提供有效视野。
