## 失衡状态

敌方单位受到任意来源的力且受力大小大于 0 时进入失衡状态，之后才能被推动或拉动（空中敌人虽然也存在重量属性，但是不会进入失衡状态）。受力等级（技能文本中的力度描述）与受力大小是两个不同的量。

## 力度等级

技能文本中的力度描述对应数值：

| 描述力度 | 力度 |
|:--|:--|
| 微小力（稍微） | -1 |
| 小力 | 0 |
| 中力 | 1 |
| 较大力 | 2 |
| 大力 | 3 |
| "大力+1" | 4 |
| 特大力 | 5 |

## 位移判定

施力前提：施力的攻击或技能命中目标，目标需在干员的攻击范围内，方向通常由干员朝向及目标的相对位置决定。

位移等级 = 力度 − 目标重量。以下为精确位移值。

### 推力（推开）

| 力度减重量 | 位移(格) | 时间(秒) |
|:--|:--|:--|
| ≤-3 | 0 | 0 |
| -2 | 0.11825 | 0.2 |
| -1 | 0.4403 | 0.4 |
| 0 | 1.6958 | 0.8 |
| 1 | 2.13705 | 0.9 |
| 2 | 2.95013 | 1.0667 |
| ≥3 | 3.52392 | 1.1667 |

上表为弹道类推力（如温蒂、阿消的技能弹道）。特效类推力（如食铁兽、见行者的技能）位移略短，差异见《位移底层机制》条目。

### 拉力（拖拽）

| 力度减重量 | 位移(格) | 时间(秒) | 说明 |
|:--|:--|:--|:--|
| ≤-3 | 0 | 0 | 无法拉动 |
| -2 | 0.03 | 0.5 | 爬行位移，与目标距离无关 |
| -1 | 0.57 / 0.92 | max(0.65 × √初始距离, 1.0) | 目标位于前 2 格 / 前 3 格处 |
| 0 及以上 | 1.33 / 2.33 | 到达急停区所需时间 | 拉至干员身前（进入急停区） |

-1 级及以上的位移精确值分别对应目标位于干员前 2 格 / 3 格处（初始距离 1.5 / 2.5 格），位移随初始距离增大而增大。

## 方向性修正

推力与拉力都分为方向力与径向力两类：

- 方向力：沿部署方向作用。推力中常见于推击手特种的技能
- 径向力：沿干员/召唤物中心指向目标的方向作用。推力中除推击手外均为径向力；拉力大部分情况下为径向力

特殊修正：方向力成立时，若目标与干员/召唤物的连线和部署方向的夹角大于 45°（即目标不在部署方向两侧各 45° 的扇形范围内，如敌人在干员身后），或目标与干员/召唤物的距离小于 0.25 格，方向力修正为径向力且受力等级 −2。部分干员技能可干预此修正，以干员描述为准。

## 实用说明

对于温蒂的液氮大炮技能，由于温蒂及其召唤物会同时发射弹道，而部署位置不同导致命中帧不同，可以借助撤退操作使弹道立即命中来实现同帧双炮以达到合力效果（召唤物部署在温蒂身后以实现温蒂弹道先命中，命中帧时撤退召唤物来达成）。
对于拉力技能，可以在敌人位移过程中未急停时撤退干员来实现最大位移距离。
