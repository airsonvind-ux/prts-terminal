## 关卡的部署费用

- **初始费用**：行动开始时预先充入的费用，大多数关卡为 10 点
- **费用回复间隔**：自然回复 1 点费用所需时间（秒），通常为 1。"部署费用速度降低"条件通过符文调整费用恢复速度倍率实现（回复间隔 × 1 ÷ 倍率）；"费用不会自然回复"类条件实为将回复间隔调整至极长
- **费用点冷却**：距离下 1 点费用回复的冷却进度，以白条显示在当前费用下方
- **最大费用上限**：可持有费用的最大值，达到后费用停止回复、溢出部分丢弃（冷却条显示 MAX）。通常为 99，剿灭作战类关卡为 999
- **部署费用下限**：可持有费用的最小值，通常为 0
- **当前费用**：当前可供调配的费用，显示在画面右下角

## 负数当前费用

可露希尔的天赋可以使部署费用下限降至 0 以下，此时出现负数当前费用：

- 当前费用回复至 0 前，费用恢复速度减半（与费用回复速度等数值乘算），除此之外无其他特殊效果
- 几乎所有费用判定（部署、特性、技能、天赋耗费）都可正常消耗负数部分的费用（即透支）；可透支或费用为负时出现负费图标提示
- 特殊能力对当前费用的检查需启用负费处理才能与费用下限交互，此时判断标准变为 费用下限 + 写出费用值；未启用则仅按正数部分判定。大多数耗费类机制启用了负费处理（如行商特性耗费），单纯的费用比较判定未启用
- "清空费用"机制实际为将部署费用重置为 0 点，负数费用会被补充到 0

## 待部署区单位的部署费用

部署费用（属性）=（初始部署费用 + 基础费用增减）× 费用倍率 + 实时费用增减

- 该属性显示在干员头像上方，既是部署所需消耗，也是系统认定的本次部署实际消耗；被部署干员继承该数据用于撤退返费
- 当前费用不足以支付时，单位无法被拖选；已拖选并放置也无法正常部署

各成分：

- **初始部署费用**：基础值，无符文干扰时等同战斗外显示的部署费用；包含精英化、潜能、模组的费用变化；关卡"费用翻倍/变为 3 倍"等符文加成直接作用于初始部署费用
- **基础费用增减**：换费效果与少量无限制自我费用减少天赋，等效于属性运算的直接加算
- **费用倍率**：默认 1.0，通常只由再部署惩罚提供，等效于直接乘算
- **实时费用增减**：大部分费用减少效果，等效于最终加算

## 再部署惩罚

干员每次退场（包括撤退、被击倒）累积一层再部署惩罚（上限两层），每层为待部署区的“自己”提供 0.5 额外费用倍率（由 UID 严格对应，同名干员不存在两个“自己”）。第二次部署费用为初始的 1.5 倍（向下取整），第三次为 2.0 倍，之后达到上限不再变化。部分离场方式（如术语移动：干员在场上发生移动、视为再部署的特殊方式，如乌尔比安三技能）不累积。

## 基础部署费用

基础部署费用 = 初始部署费用 + 基础费用增减。作为"打乱费用""费用交换"等机制的参考值，也是撤退返费的上限值。

## 撤退返费

干员因"撤退"原因离场（手动撤退、强制撤退、自动撤退）时，通常返还本次部署消耗费用的一定比例：

- **返还倍率**：大部分召唤物、装置、特种-行商为 0%，先锋-冲锋手为 100%，其他大部分干员为 50%
- **返还量** = 部署费用（属性）× 返还倍率 与返还上限取小后向下取整；返还上限通常等于基础部署费用
- 部署费用（属性）可受实时费用增减影响，基础部署费用不受影响，因此可能出现"部署费用高、返还上限低"的情况
- 除手动部署与手动撤退外，大部分其他部署/撤退方式会将本次部署标记为不可返费，撤退时不返还任何费用
- "无视返还上限"（部分模组）：将返还上限改为与部署费用（属性）相同，实现返还"该次部署费用"的效果
